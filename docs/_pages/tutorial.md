## Goal

Is to create a short story, about a page long, made in Markdown.

This will allow us to learn the basic syntax, features, and styling of the document. Learning Markdown is an easy first step to creating a simple website to finally create that novel, portfolio, or blog you always wanted to share.

## Getting Started

## Text Formatting

Headers, italics, bold, blockquotes, and horizontal rules.

## Links and Media

Links, images, and embedded videos.

## Code and Lists

Inline code, code blocks, ordered lists, and unordered lists.

## Extended Markdown

Tables, task lists, and strikethrough, with notes about GFM compatibility.
