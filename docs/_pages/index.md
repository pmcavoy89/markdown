## README

Markdown is a lightweight markup language that allows you to write using an easy-to-read, easy-to-write plain text format.

This project is intended to teach everyone how to create beautifully styled documents for the modern web.

## Goal

To enrich our written communication for the web.

## Materials

- Computer with internet access
- Access to an online Markdown editor (e.g., [Dillinger](https://dillinger.io), [StackEdit](https://stackedit.io/app#))
